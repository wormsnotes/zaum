# Заумь затрапезная

Личная страница с кнопкой, открывающей игру «Змейка». Обычные HTML, CSS и JavaScript: без установки пакетов, сборки и внешних зависимостей.

## Посмотреть на компьютере

Откройте `index.html` в браузере. Интернет для работы сайта не требуется.

## Игра

- Нажмите «Играть в змейку» — игра начнётся в отдельном окне.
- Стрелки, WASD (также ЦФЫВ в русской раскладке), свайпы и экранные кнопки управляют змейкой.
- Собирайте фиолетовые яблоки. Каждое яблоко добавляет одно очко и немного ускоряет игру.
- Столкновение со стеной или собственным телом завершает игру.
- Пробел при фокусе на поле или кнопка «Пауза» останавливают игру.
- «Заново» начинает новую попытку, Esc или крестик закрывают окно.
- При смене вкладки или потере фокуса окна игра автоматически ставится на паузу.
- Личный рекорд сохраняется в браузере, если браузер разрешает локальное хранилище. Это не общий рейтинг посетителей.

## Опубликовать на GitHub Pages

1. Войдите в свой аккаунт на https://github.com и создайте **новый публичный репозиторий** `zaum`. Добавлять лицензию или README при создании необязательно: README уже есть в этой папке.
2. В репозитории выберите **uploading an existing file** (или **Add file → Upload files**).
3. Загрузите содержимое этой папки: `index.html`, `style.css`, `script.js`, `favicon.svg`, `README.md` и `.nojekyll`. Файл `index.html` должен быть прямо в корне репозитория, без дополнительной папки `zaum` внутри него. `.gitignore` можно также загрузить, если он отображается в диалоге выбора.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку **main** и папку **/ (root)**, нажмите **Save**.
7. Дождитесь публикации (обычно несколько минут, иногда до 10). На странице **Settings → Pages** появится ссылка **Visit site**.
8. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/zaum/`. Откройте его в приватном окне и на телефоне, затем отправляйте друзьям.

Если GitHub предлагает другую основную ветку вместо `main`, выберите ту, в которую загрузили файлы.

Сайт и его исходные файлы будут публичными. Собственный домен и платный хостинг для этого варианта не нужны.

Чтобы обновить сайт, загрузите изменённые файлы в тот же репозиторий и подтвердите **Commit changes**. GitHub Pages опубликует изменения по прежнему адресу.

Официальные инструкции:
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Файлы

- `index.html` — страница и окно игры.
- `style.css` — оформление и адаптация для телефона.
- `script.js` — логика змейки, управление и рекорд.
- `favicon.svg` — значок вкладки браузера.
- `.nojekyll` — отключает ненужную для этого сайта обработку Jekyll.

Все пути к ресурсам относительные: сайт работает и на GitHub Pages в подпапке `/zaum/`, и при открытии с компьютера.
